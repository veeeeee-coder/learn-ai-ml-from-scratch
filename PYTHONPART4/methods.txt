INSTANCE
class Laptop:
storage_type="ssd"

def __init__(self,RAM,storage):
self.RAM=RAM
self.storage=storage

def get_info(self):
print(f" laptop has {self.RAM} RAM & {self.storage} {self.storage_type}")


l1=Laptop("16gb","512gb")
l1.get_info()


INSTANCE
1. 1st param -> self
2. access the class and instance attributes





CLASS
to make a function a class use a decorator 
@classmethod
def get_storage_type(cls):
print(f"storage type= {cls.storage_type}")

Laptop.get_storage_type()
or
l1.get_storage_type()
