LOOPS lets us execute a block of code multiple times
(either a set no of times or until a condition is met)

.while
.for

i=1
while(i<=5):
print(i)
i++

(if an condition always gives out true its an infinite loop which we shoudl freakin avoid)

LOOP CONTROL STATEMENTS
tools to control how loops behave
.break
.continue

1.break-stops loop immediately
2.continue-skips current iteration and moves to next iteration

FOR LOOP
normally used to iterate over a sequence (list,tuple) 

for i in range(5):
print(i)

(IN is a membership operator to check the presence of an item)

NESTED LOOPS
loop in loop 
for i in range(1,3):
for j in range(1,3):
print(f" {i},{j}")

RANGE()
used to generate a sequence of numbers
it creates an iterator that produces number one by one

function has 3 parameters
1.start(default=0)
2.stop(number to stop before)
3.step
